# ThunderbirdAI branding

This is the local custom-build branding for ThunderbirdAI.  It is based on
the existing nightly branding so the build keeps its normal packaging
structure, but the Linux application icon sizes are replaced with the red
bird-and-envelope icon in `assets/red-thunderbirdai-icon.png`.

`default16.png` through `default256.png` are the size-specific build assets.
They are generated from the source PNG so the launcher, window, and task
switcher consistently identify this custom build.
