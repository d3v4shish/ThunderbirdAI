# Security policy

## Supported versions

This repository is an experimental source snapshot, not a supported
Thunderbird distribution. No release currently receives security backports.

## Reporting a vulnerability

Do not disclose a suspected vulnerability, credential, or private-mail sample
in a public issue. Use GitHub's **Security > Report a vulnerability** flow for
this repository so the report can be discussed privately. If that option is
not available, contact the repository owner through a private channel without
including exploit details in the initial message.

Include the affected bundle entry, relevant revision, impact, and a minimal
reproduction that contains no real mailbox data or secrets. If the issue also
affects upstream Thunderbird or Mozilla code, follow the upstream project's
security-reporting process as well.
